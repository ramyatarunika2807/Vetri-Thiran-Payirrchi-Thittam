# Project Demonstration

## Demonstration Flow

### 1. Show the Employee Training Table
Demonstrate the table containing:
- Training Name
- Completion Date
- Status
- Employee

### 2. Show Imported Data
Open Employee Training Records and demonstrate the imported training records.

### 3. Show Dot-Walking
Show the Employee reference and the Department information obtained through dot-walking.

### 4. Show User and Role
Demonstrate the backup user and the HR Manager role.

### 5. Show ACL Configuration
Demonstrate the Read and Write ACL configuration for Employee Training Records.

### 6. Demonstrate Access Control
- Impersonate an authorized user and show that the records/fields are accessible and editable.
- Impersonate another user and show that the table is not visible.

## Final Outcome
The demonstration should show data import, related employee information, role assignment and ACL-based access control working together.
